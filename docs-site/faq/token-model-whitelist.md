# 令牌需要设置可用模型吗？

**通常情况下，不需要，也不建议设置。**

## 为什么不建议设置？[​](/faq/token-model-whitelist#为什么不建议设置 "为什么不建议设置？的直接链接")

在创建或编辑令牌时，有一项 "可用模型" 的配置。

- **默认（留空）：** 该令牌可以调用平台支持的所有模型（包括未来上线的新模型）。
- **指定模型：** 该令牌**只能**调用您选中的那几个模型。

如果您指定了模型，当平台上线了更强的新模型（例如 GPT-5）时，您的这个 Key 将无法直接调用，必须手动回来修改配置，这会带来维护麻烦。

## 什么时候需要设置？[​](/faq/token-model-whitelist#什么时候需要设置 "什么时候需要设置？的直接链接")

仅在以下特殊场景建议设置模型白名单：

1. **外包/第三方使用：** 您将 Key 提供给外部开发者，只想让他们使用便宜的 `gpt-4o-mini`，禁止使用昂贵的 `claude-3-opus`。
2. **特定的安全策略：** 您的应用逻辑只兼容特定模型，为了防止误调用其他模型导致错误。
3. **预算严格控制：** 强制限制只能使用低价模型。

## 注意事项[​](/faq/token-model-whitelist#注意事项 "注意事项的直接链接")

如果您设置了模型白名单，请务必确保您选择的模型名称（Model ID）是正确的。
