# 价格说明

ArmNet 字元服务致力于提供极具竞争力的价格，同时保障服务的高质量和稳定性：

1. **海外模型价格同步**：OpenAI、Claude、Gemini、Grok 等海外大模型，**价格与官方完全一致**。
2. **国产模型更优惠**：DeepSeek、Qwen、豆包、Kimi 等国产大模型，**价格低于官方**。
3. **稀缺模型溢价低**：部分稀缺或新出的海外大模型（官方未开放 API 或限制极多），价格可能会略高，但结合充值优惠后，**接近官方原价**。

## 🧾 计费基础知识[​](/pricing#-计费基础知识 "🧾 计费基础知识的直接链接")

### 1. 按量计费 (Pay-as-you-go)[​](/pricing#1-按量计费-pay-as-you-go "1. 按量计费 (Pay-as-you-go)的直接链接")

- **无需订阅**：没有月费/年费，没有最低消费。
- **用多少付多少**：每一分钱都花在实际调用上。
- **随时停用**：余额不过期（特定活动赠金除外）。

### 2. 计费模式优先级[​](/pricing#2-计费模式优先级 "2. 计费模式优先级的直接链接")

部分模型（如图像/视频生成）可能同时支持“按次计费”和“按量计费”：

- **默认优先按次计费**：如果模型支持按次计费，系统默认采用按次计费。
- **API Key 设置**：您可以在创建 API Key 时，强制指定“仅按量计费”或“仅按次计费”来控制成本。

### 3. 常见计费单位[​](/pricing#3-常见计费单位 "3. 常见计费单位的直接链接")

- **按次计费**：通常用于生图、生视频。
- **Tokens (代币)**：用于文本模型。
  - **定义**：Token 是 AI 模型处理文本的基本单位。
  - **换算**：
    - 1 个汉字 ≈ 1-2 Tokens
    - 1 个英文单词 ≈ 1-2 Tokens
    - 1000 Tokens ≈ 750 个英文单词 ≈ 500 个汉字
  - **构成**：费用 = 输入 Tokens (Prompt) + 输出 Tokens (Completion)。通常输出 Tokens 价格高于输入 Tokens。

## 📊 成本预估方法[​](/pricing#-成本预估方法 "📊 成本预估方法的直接链接")

1. **小样本测试**：先用 5-10 条数据进行测试。
2. **查看消耗**：在 ArmNet 字元服务 个人中心查看详细的 Token 消耗记录。
3. **计算平均值**：得出单次调用的平均 Token 数。
4. **预估总成本**：平均 Tokens × 预计调用次数 × 模型单价。
