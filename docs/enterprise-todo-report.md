# 企业版后续待办报告

本文记录当前企业、成员、管理员功能在现有实现基础上的待办事项。已经实现的能力不再重复列为待办。

## 1. 近期必须处理

### 1.1 资金流水与审计

当前资金已经分为个人余额、企业资金、成员企业额度，但资金操作仍缺少统一流水页面。

待实现：

- 用户个人余额变动流水。
- 企业资金池变动流水。
- 成员额度分配/回收流水。
- 企业 API Key 消费流水。
- 管理员调账审计：操作者、目标用户/企业、操作前余额、操作后余额、原因。
- 企业主个人余额划转企业资金的专用流水。
- CSV/Excel 导出。

### 1.2 企业资金退回个人余额

当前企业主可以将个人余额划转到企业资金，但不能自行退回。

待实现：

- 管理员从企业资金退回创建者或指定用户个人余额。
- 退回前二次确认。
- 退回原因必填。
- 退回记录写入审计流水。
- 明确已解散企业是否允许退回资金。

### 1.3 邀请记录管理

当前支持邮件邀请和邀请链接接受，但企业主看不到完整邀请记录。

待实现：

- 企业主查看邀请列表。
- 邀请状态：待接受、已接受、已过期、已撤销。
- 重发邀请邮件。
- 撤销邀请。
- 设置邀请有效期。
- 管理员查看所有企业邀请记录。

### 1.4 低余额提醒闭环

当前已有 `BalanceEmailNotifyEnabled` 和 `BalanceWarningPercent` 配置基础。

待实现/待验收：

- 企业资金低于阈值时给企业创建账户邮箱发送提醒。
- 成员企业额度低于阈值时给成员邮箱发送提醒。
- 个人余额低于阈值时给用户邮箱发送提醒。
- 防重复发送策略，例如每个阈值周期只发送一次。
- 站内提醒或通知中心。
- 管理员设置页完整接入开关与百分比。

## 2. 企业主功能完善

### 2.1 企业资料

当前企业资料主要是名称。

待实现：

- 企业 Logo 上传、预览、删除。
- 企业类型：企业、团队、家庭、个人项目。
- 联系邮箱。
- 联系人。
- 备注。
- 账单/税务信息。
- 企业资料编辑历史。

### 2.2 成员权限拆分

当前只有企业主和成员两类角色。

待实现角色：

- 企业主。
- 企业管理员。
- 财务管理员。
- 普通成员。
- 只读成员。

待实现权限点：

- 是否能邀请成员。
- 是否能移除成员。
- 是否能分配额度。
- 是否能查看企业全量日志。
- 是否能查看成员 API Key 元数据。
- 是否能创建企业扣费 API Key。
- 是否能管理企业资料。

### 2.3 企业 API Key 管理增强

当前企业主可查看成员企业 API Key 元数据。

待实现：

- 按成员筛选。
- 按 Key 状态筛选。
- 按模型限制筛选。
- 按最近使用时间排序。
- 批量禁用企业 Key。
- 识别长期未使用 Key。
- 识别解散/异常企业残留 Key。

## 3. 成员功能完善

### 3.1 成员 API Key 安全体验

待实现：

- 创建后只显示完整 API Key 一次。
- 企业扣费 Key 创建成功后明确提示扣费来源。
- 成员 API 页面支持禁用、删除、编辑自己的企业 Key。
- 成员 API 页面支持搜索和分页。
- 外部客户端配置说明内嵌入口。

### 3.2 成员历史视图

当前退出企业后历史日志仍保留在后台。

待明确并实现：

- 成员退出后是否还能查看自己在该企业的历史消费。
- 企业解散后成员是否还能查看历史企业 Key 元数据。
- 管理员是否能导出成员历史账单。

## 4. 管理员功能完善

### 4.1 企业详情增强

已有管理员企业详情页。

待实现：

- 企业资金流水 tab。
- 成员额度流水 tab。
- 企业邀请记录 tab。
- 企业 API Key 独立列表，支持搜索、分页、状态筛选。
- 管理员禁用某企业所有 API Key。
- 管理员冻结/恢复企业。
- 管理员恢复企业主关系。

### 4.2 用户资金管理增强

已有管理员管理用户资金入口。

待实现：

- 调账原因必填。
- 调账前后余额展示。
- 调账记录列表。
- 批量导出。
- Root 用户高风险操作二次验证。

### 4.3 数据修复工具

待实现：

- 一键停用无有效企业关系的企业 API Key。
- 检查企业资金与成员剩余额度是否一致。
- 检查成员关系是否重复。
- 检查邀请是否过期但仍为 pending。
- 检查重复邮箱/用户名历史数据。

## 5. 正式支付与财务

当前没有正式充值/支付流程。

待实现：

- 充值订单。
- 支付渠道接入。
- 支付回调验签。
- 支付成功入账。
- 支付失败/超时处理。
- 退款或冲正。
- 发票/账单信息。
- 管理员手动加款审计。
- 企业对账单。

## 6. 外部客户端文档

待补充：

- Base URL 如何填写。
- 是否需要 `/v1`。
- OpenAI 兼容客户端配置示例。
- VS Code/Codex 插件配置示例。
- Chatbox、Cherry Studio 等客户端配置示例。
- 企业扣费 Key 和个人 Key 的区别。
- Key 失效、企业解散、成员退出后的表现。

## 7. 数据库与并发

待验证：

- SQLite、MySQL、PostgreSQL 三种数据库均可迁移。
- 企业资金划转事务一致性。
- 成员额度分配并发一致性。
- 企业 API Key 并发扣费不会扣成负数。
- 预扣、结算、退款链路在企业额度下正确。
- Redis 缓存开启时用户余额、Token 状态、企业 Key 失效一致。

## 8. 上线前验收清单

- 注册、登录、退出无串号。
- 普通用户无法访问管理员企业页。
- 成员无法伪造其他企业 `enterprise_id` 创建 Key。
- 个人 Key 只扣个人余额。
- 企业 Key 只扣成员企业额度。
- 企业解散后旧企业 Key 无法使用且无法重新启用。
- 成员退出后企业 Key 停用。
- 成员移除后未用企业额度退回企业资金。
- 企业主划转个人余额到企业资金后，个人余额减少、企业资金增加。
- 企业主解散企业时有余额则禁止。
- 管理员企业列表和详情页搜索、分页正常。
- `bun run typecheck` 通过。
- `bun run build` 通过。
- `go test ./model ./controller` 或核心包测试通过。
